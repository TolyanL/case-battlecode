УМНЫЙ ДОМ / УПРАВЛЕНИЕ СОЛНЕЧНЫМИ ПАНЕЛЯМИ Python

Задача:

Требуется написать программу, которая отвечает за функционирование солнечных панелей.

  • Автоматическое **переворачивание панелей** при осадках (снег/дождь), определяемых датчиками.
  • Обеспечение следования панелей **направлению солнца** для максимальной энергоэффективности.

Ключевые характеристики:

Время на проверку

🕒 45 min

Время на выполнение

🕒 30 hrs

Награда (Очки)

➕ 15 командных

➕ 40 python

Сложность
Сложный

Подробности

Требуется составить программу, которая может переворачивать солнечные панели в зависимости наличия на ней осадков в виде снега или дождя. Она должна определять есть ли подобные вещи на панели при помощи датчиков. Также требуется чтобы панели следовали в направлении солнца для максимальной энергоэффективности.
